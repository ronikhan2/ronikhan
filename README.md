Roni Khan Portfolio — GitHub Pages upload structure

The repository must contain these exact paths:

index.html
assets/images/profile.jpg
assets/images/spiscon-2026.jpg
assets/docs/Roni_Khan_CV.pdf

IMPORTANT: GitHub file names are case-sensitive. Do not rename Profile.jpg, profile.JPG, SPISCON.jpg, etc.
The HTML expects exactly:
  profile.jpg
  spiscon-2026.jpg
  Roni_Khan_CV.pdf

GitHub web upload method:
1. Open your ronikhan repository and select the Code tab.
2. Replace index.html with the provided index.html and commit it.
3. If assets/images does not exist: Add file > Create new file, type assets/images/.gitkeep, add any text, and Commit changes.
4. Open assets, then images. Click Add file > Upload files. Upload profile.jpg and spiscon-2026.jpg. Commit changes.
5. If assets/docs does not exist: Add file > Create new file, type assets/docs/.gitkeep, add any text, and Commit changes.
6. Open assets, then docs. Click Add file > Upload files. Upload Roni_Khan_CV.pdf. Commit changes.
7. Confirm these browser URLs open directly:
   https://ronikhan2.github.io/ronikhan/assets/images/profile.jpg
   https://ronikhan2.github.io/ronikhan/assets/images/spiscon-2026.jpg
   https://ronikhan2.github.io/ronikhan/assets/docs/Roni_Khan_CV.pdf
8. Finally open https://ronikhan2.github.io/ronikhan/ and press Ctrl+F5.
