Undergraduate thesis

FarmChat: LLM-RAG-Powered Framework for Real-Time Tomato Leaf Disease Detection and Farmer Assistance

Supervisor: Dr. A.T.M. Saiful Islam
  • Developed an end-to-end AI framework for real-time tomato leaf disease detection using YOLO11.
  • Integrated Large Language Models with Retrieval-Augmented Generation for bilingual Bangla-English agricultural decision support.
  • Designed an explainable AI-assisted pipeline to improve reliability and interpretability of diagnosis and recommendations.
  • Developed a prototype chatbot for disease diagnosis, cultivation guidance and treatment recommendations through natural-language interaction.
  • Evaluated the framework using publicly available plant-disease datasets for practical precision-agriculture use.
